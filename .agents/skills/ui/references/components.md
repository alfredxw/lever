# 按交互场景选择组件

表中列出 Lever 现有组件和可按需引入的 shadcn 组件。先查本地实现和变体，新增时按项目的 `radix-nova` 配置核对官方 API 和依赖。 [共享 UI 组件](../../../../web/src/components/ui/) · [项目配置](../../../../web/components.json) · [shadcn/ui 组件目录](https://ui.shadcn.com/docs/components#all-components)

## 操作与菜单

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Button` | 触发一个明确的操作。 | 新建 Agent、保存设置 |
| `ButtonGroup` | 把紧密相关的操作并排显示为一组。 | 运行与运行选项、上一项与下一项 |
| `DropdownMenu` | 从按钮打开一组操作。菜单内的单选偏好或独立开关可用 `DropdownMenuRadioItem` 或 `DropdownMenuCheckboxItem`。 | 更多操作、列表排序 |
| `ContextMenu` | 通过右键打开当前对象的操作，重要操作同时提供可见入口。 | 文件重命名、复制路径 |
| `Menubar` | 在桌面式界面顶部常驻多组全局命令。 | 文件、编辑、视图菜单 |
| `Command` | 通过输入搜索命令、操作或跳转目标。 | 全局命令面板、按名称跳转文件 |
| `Kbd` | 在说明或菜单中展示按键和快捷键。 | 搜索入口的 ⌘K、编辑菜单的撤销快捷键 |

## 开关、选项与筛选

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Switch` | 开关一个独立功能，通常立即生效。 | 桌面通知、自动化启用 |
| `Toggle` | 用按钮的按下状态表示一个可切换的模式或筛选条件。 | 编辑器加粗、仅看未完成 |
| `ToggleGroup` + `ToggleGroupItem` | 把少量可切换选项并排显示。互斥模式用 `type="single"`，可叠加的选项用 `type="multiple"`。 | 列表与网格切换、粗体与斜体、常用筛选 |
| `RadioGroup` + `RadioGroupItem` | 表单单选，需要同时展示各选项的标签或说明。 | 权限级别、执行方式 |
| `Checkbox` | 勾选一个项目，或从一组可见选项中勾选零到多项。表单分组可配 `FieldSet` 和 `FieldLegend`。 | 批量选择文件、订阅事件类型 |
| `Select` | 选项较多或空间有限，用户可直接浏览下拉列表选一个值。 | 界面语言、日志级别 |
| `NativeSelect` | 单选字段需要沿用浏览器或系统的原生选择交互。 | 移动端表单选择年份或地区 |
| `Combobox` | 选项较多或动态变化，需要输入搜索后选择。 | 搜索 Agent、分支、项目 |
| `Combobox`（`multiple`） | 从可搜索的列表选多项，显示已选项并支持逐个移除。 | 标签、团队成员 |

可搜索单选优先复用 `SearchableSelect`。需要定制时，参考分支选择器中的 `Popover` + `Command`。 [SearchableSelect](../../../../web/src/components/ui/searchable-select.tsx) · [分支选择器](../../../../web/src/features/diff/BranchPicker.tsx) · [Combobox](https://ui.shadcn.com/docs/components/radix/combobox)

必须保留一个值的 `ToggleGroup` 单选，在受控回调中忽略取消当前项产生的空值。

## 表单与输入

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Field` | 组合字段标签、控件、说明和校验错误，统一表单字段布局。 | Agent 设置、必填项校验 |
| `Label` | 为独立控件提供可见且关联到控件的标签。 | 通知开关名称、搜索框标签 |
| `Input` | 输入单行内容。精确录入数值时用 `type="number"`。 | Agent 名称、重试次数 |
| `Textarea` | 输入多行纯文本。 | 任务说明、Agent 指令 |
| `InputGroup` | 将输入框与单位、图标或附属操作组合为一个控件。 | 数量加减、清空搜索、显示密码 |
| `InputOTP` | 输入按位呈现的固定长度验证码。 | 登录验证码、邮箱校验码 |
| [`Slider`](https://ui.shadcn.com/docs/components/radix/slider) | 在有上下限的范围内拖动取值。单滑块调节一个值，双滑块选择区间。 | 亮度、音量、价格范围 |
| `Calendar` | 在页面上直接浏览日期并选择单日或范围。 | 查看每日运行记录、选择排期 |
| [`Date Picker`](https://ui.shadcn.com/docs/components/radix/date-picker)（`Popover` + `Calendar`） | 在日期字段旁按需展开日历。用 `mode="single"` 或 `mode="range"` 选日期，按需另配时间输入。 | 开始日期、报表日期范围 |
| `Questionnaire` | 逐步收集单选、多选或自由回答，可允许跳过。 | Agent 澄清需求、分步配置 |

## 导航与布局

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Sidebar` / `SecondarySidebar` | 提供可折叠的侧栏导航。工作台二级导航复用 `SecondarySidebar`。 | Agent 列表、设置分类 |
| `NavigationMenu` | 组织顶部横向导航链接，可展开分组链接。 | 文档站导航、产品模块入口 |
| `Breadcrumb` | 显示当前位置的层级路径，支持返回祖先层级。 | 嵌套目录、项目内资源详情 |
| `Tabs` + `TabsList` + `TabsTrigger` + `TabsContent` | 在同一页面的多个内容面板间切换。 | 概览、活动与设置面板 |
| `Pagination` | 列表按页展示，用户需要翻页或跳到指定页。 | 搜索结果、审计记录 |
| `Resizable` | 并排面板需要由用户调整大小。 | 编辑器与预览、会话与文件树 |
| `ScrollArea` | 独立滚动区域需要统一的滚动条样式。 | 长菜单、固定高度的日志面板 |
| `Collapsible` | 由一个触发器展开或收起一块内容。 | 高级设置、更多详情 |
| `Accordion` | 将多块同级内容按标题排列，可逐块展开。 | 常见问题、分组设置 |
| `Direction` | 为页面或局部区域及其组件统一设置从右到左的交互方向。 | 阿拉伯语或希伯来语界面 |

## 内容与数据展示

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Card` | 将同一对象的标题、内容和相关操作放进一个独立容器。 | Agent 概览卡、任务摘要 |
| `Item` | 用统一的行布局展示单个对象的图标、名称、说明和操作。 | Skill 列表、连接列表 |
| `Badge` | 给对象附上简短的状态或分类标签。 | 已启用、Beta、技能来源 |
| `Avatar` | 通过头像或回退内容识别人员或 Agent。 | 任务负责人、会话发言者 |
| `Separator` | 划分相邻内容或操作组的边界。 | 侧栏分区、工具栏分组 |
| `AspectRatio` | 容器随宽度变化时，保持媒体的展示比例。 | 视频封面、截图缩略图 |
| `Carousel` | 在有限空间内逐张浏览一组同类内容。 | 附件图片预览、截图浏览 |
| `Typography` | 统一阅读内容的标题、段落、列表和引用样式。 | 帮助文档、Markdown 预览 |
| `Table` | 以行列对齐展示结构一致的数据，主要用于浏览和比较。 | 运行记录、配置参数 |
| `Data Table`（`Table` + TanStack Table） | 表格需要排序、筛选、分页或行选择。 | 任务明细、可批量处理的记录列表 |
| `Chart` | 通过图形查看趋势、比较数值或观察分布。 | 耗时趋势、运行次数对比 |
| `CodeBlock` | 展示保留格式的代码或输出，按需提供行号、复制和差异标记。 | 代码片段、命令输出、文本 diff |

## 浮层与预览

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Tooltip` | 悬停或聚焦时补充简短的说明。图标按钮保留自己的可访问名称。 | 图标操作含义、键盘快捷键 |
| `HoverCard` | 悬停链接时预览附加信息，完整内容可通过链接打开。 | 人员简介、链接摘要 |
| `Popover` | 在触发按钮旁展开少量可交互内容，也可放入一组相关表单控件。 | 高级筛选、显示选项 |
| `Dialog` | 暂时聚焦一个需要独立完成的操作或表单。 | 创建连接、编辑任务设置 |
| `AlertDialog` | 高影响操作需要用户先确认或取消。 | 删除 Agent、丢弃未保存的修改 |
| `Sheet` | 从屏幕边缘展开需要较多空间的补充内容或编辑面板。 | 文件详情、编辑任务属性 |
| `Drawer` | 在触屏上从屏幕边缘展开内容，需要支持拖动收起。 | 移动端筛选、底部操作面板 |

## 状态与反馈

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Empty` | 列表为空或筛选无匹配项时，说明当前状态并按需给出下一步。 | 尚无任务、搜索无结果 |
| `Alert` | 在相关区域持续显示需要留意的状态或处理办法。 | 连接失败、权限不足 |
| `Toast` / `Sonner` | 短暂反馈操作结果，可带撤销入口。Lever 复用已接入的 `Sonner`。 | 复制成功、归档后撤销 |
| `Skeleton` | 加载内容时，按已知布局提前占位。 | Agent 列表、详情页首屏 |
| `Spinner` | 表示某个操作正在进行且完成度未知。 | 等待保存、刷新列表 |
| `Progress` | 显示可量化的任务完成度。 | 上传进度、已导入条目数 |

## 会话与 Agent 运行

| 组件或组合 | 何时使用 | 典型场景 |
| --- | --- | --- |
| `Message` | 组织一条消息的发送者、正文和相关操作。 | 用户提问、Agent 回复 |
| `Bubble` | 用气泡呈现会话内容，按发送方对齐或分组。 | 连续发送的消息、可折叠的长消息 |
| `Attachment` | 展示消息或输入区的附件，可附预览、上传状态和操作。 | 图片附件、待发送文件 |
| `MessageScroller` | 管理会话滚动，支持跟随流式回复、加载历史时保持位置和定位消息。 | Agent 会话、定位到某条历史消息 |
| `Marker` | 在消息之间展示系统事件、状态或分隔。 | 切换分支、会话已压缩 |
| `Trace` | 展示 Agent 的运行步骤、状态和可展开的细节。 | 工具调用、子 Agent 执行记录 |
