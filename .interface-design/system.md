# Lever 界面规范

## Changes 工具栏

工具栏沿用工作台的中性色与 Geist 字体。范围和变更统计位于左侧，操作位于右侧，代码内容保持主要视觉层级。间距以 2px 为基础，操作按钮间距固定为 3px。全局交互规范见 [AGENTS.md](../AGENTS.md)。

| 元素       | 尺寸                                                       |
| ---------- | ---------------------------------------------------------- |
| 工具栏     | 最小高度 48px；上下内边距 6px，左右 12px；控件组间距 8px   |
| 窄内容区   | 内容区宽度不超过 700px 时，左右内边距 8px                  |
| 胶囊       | 高度 34px；内边距 2px；边框 1px；圆角 999px                |
| 范围按钮   | 使用 `Button` 的 `sm` 尺寸，高度 28px；文字 13px           |
| 范围与统计 | 间距 8px；胶囊右侧内边距 12px；统计文字 12px               |
| 图标按钮   | 使用 `FileAction` 的 `icon-sm` 尺寸，28px × 28px；间距 3px |

窗口宽度不超过 760px 时，控件组间距为 5px。空间不足时，胶囊按组换行。

### 胶囊表面

项目与范围、分支比较、操作区共用柔和的半透明胶囊表面。背景来自 `--popover`，不透明度为 85%；边缘来自 `--foreground`，不透明度为 8%。背景模糊半径为 12px。

深度由一条内侧高光和两层轻微投影组成。浅色主题使用 90% 白色高光和 6% 黑色投影；深色主题使用 6% 白色高光和 24% 黑色投影。胶囊内部的按钮通过底色和图标颜色显示状态。

### 按钮状态

自动换行、全部折叠、双栏视图和文件侧栏通过 `aria-pressed` 显示当前状态。开启时，按钮使用 10% `--foreground` 底色和 `--foreground` 图标；关闭时，图标使用 `--muted-foreground`。

悬停、键盘焦点和菜单展开使用 6% `--foreground` 底色。选中状态的优先级高于悬停和焦点状态。焦点不增加 ring、outline 或发光阴影。文件侧栏开关使用 `Folders` 图标。

### 项目与分支选择

多 Scope 时，项目选择位于左侧胶囊内部、范围选择之前。Branch 模式在相邻胶囊内显示 `基础分支 → 目标分支`。两个分支都支持搜索和键盘选择，选择后立即更新比较结果。分支菜单宽度为 320px，列表项最小高度为 34px。

每个 Scope 保留独立的分支选择。初始基础分支来自仓库的远程默认分支；缺少该信息时，依次使用 `main`、`master`、对应远程分支或当前分支。目标分支初始为当前分支。Committed 模式在范围按钮中显示提交的短哈希；切换项目后使用该项目的 `HEAD`。

实现位于 [index.css](../web/src/index.css)、[Diff.tsx](../web/src/features/diff/Diff.tsx) 和 [BranchPicker.tsx](../web/src/features/diff/BranchPicker.tsx)。
